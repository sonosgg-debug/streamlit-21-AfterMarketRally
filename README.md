# 한국 증시 애프터마켓(KRX & NXT) 급변 종목 스크리너

당일 정규장 공식 종가(15:30)와 시간외 애프터마켓(16:00~20:00 / NXT 15:40~20:00)의 마지막 거래 가격 및 거래량을 정밀 비교하여, 유의미한 수급을 동반한 급격한 가격 변화 종목을 스크리닝하는 대시보드 웹 애플리케이션입니다.

---

## 📌 주요 핵심 기능

1. **KRX & NXT 상호보완적 실시간 스크리닝**:
   - **다음(Daum) 금융**: 15:30 KRX 정규장 공식 확정 종가 및 KRX 시간외(애프터마켓) 체결 가격을 왜곡 없이 정밀 수집
   - **네이버(Naver) 증권**: KRX 누적 거래량(C) 및 대체거래소(NXT) 누적 거래량(D) 고속 배치 수집
   - **통합 분석**: 두 금융 포털의 실시간 데이터를 상호 보완하여 가격과 수급의 실측치를 왜곡 없이 정합 분석
2. **사이드바 '시장/필터 설정' 패널**:
   - 데이터 기준 안내 배너 (KRX & NXT 상호보완 체계)
   - 시장 선택 (`전체`, `코스피`, `코스닥`)
   - 대상 범위 (`시총 상위 200개 (쾌속 모드)`, `시총 상위 500개 (권장 모드)`, `코스피 200/코스닥 150`, `전체 종목`)
   - 최소 시가총액 (억 원) 슬라이더
   - 스마트 수급 필터 (최소 NXT 비중 %, 최소 시간외 거래대금, NXT 활성 거래주 선별)
3. **엑셀 형식 데이터 표시 및 완벽한 헤더 토글 정렬**:
   - **1행 헤더 10개 컬럼**: 종목명, 종목코드, 시장, 시가총액, KRX 정규장 종가, KRX 시간외 가격, 시간외 등락률(%), KRX 거래량, NXT 거래량, NXT 비중(%)
   - **NXT 비중(%) 산출 공식**: `{NXT 거래량(D) / (KRX 거래량(C) + NXT 거래량(D))} * 100`
   - 웹 화면의 인터랙티브 테이블에서 열 헤더 클릭 시 즉시 오름차순/내림차순 토글 정렬
4. **AutoFilter가 완비된 엑셀(.xlsx) 파일 다운로드**:
   - `📥 엑셀 파일 다운로드` 버튼 클릭 시 `openpyxl`의 AutoFilter가 주입되어, 다운로드한 엑셀 파일 내에서도 각 컬럼별 역삼각형(▼) 토글 필터/정렬이 기본 활성화됨.
5. **전문가용 시각적 분석 도구**:
   - 상단 실시간 세션 바 (현재 KST 시간, 정규장/NXT/KRX 애프터마켓 운영 상태 판정)
   - 상단 핵심 KPI 요약 카드 4종 (스크리닝 종목수, 시간외 최대 급등주, NXT 비중 1위, 시간외 거래대금 1위)
   - Plotly 기반 수급-가격 모멘텀 4분면 스캐터 플롯 (1사분면 주도주 후보군 하이라이트)

## 🛠️ 실행 방법

### 방법 1. 배치 파일 실행 (가장 간편)
프로젝트 폴더 내 `run_app.bat`을 더블 클릭합니다.

### 방법 2. 명령 프롬프트(CLI) 실행
```bash
python -m streamlit run app.py
```
브라우저에서 `http://localhost:8501`로 자동 연결됩니다.
