# 한국 증시 애프터마켓(KRX & NXT) 급변 종목 스크리너

당일 정규장 공식 종가(15:30)와 시간외 애프터마켓(16:00~20:00 / NXT 15:40~20:00)의 마지막 거래 가격 및 거래량을 정밀 비교하여, 유의미한 수급을 동반한 급격한 가격 변화 종목을 스크리닝하는 대시보드 웹 애플리케이션입니다.

---

## 📌 주요 핵심 기능

1. **클라우드(GitHub Actions) 기반 15:30 무인 스냅샷 수집 체계**:
   - **무인 자동화**: 월~금 매일 15:32 KST(정규장 마감 직후)에 GitHub Actions 가상머신이 시총 상위 600개 종목의 정규장 마감 시세를 자동 수집하여 저장소에 보관
   - **무충돌 로딩**: 로컬 PC가 15:30에 꺼져 있어도 GitHub Raw URL을 통해 최신 스냅샷을 0.1초 만에 안전하게 로드 (Git 버전 충돌 0%)
   - **정밀 차감 분석**: `현재 실시간 누적 거래량/대금 - 15:30 스냅샷 마감 거래량/대금`을 통해 **순수 시간외 거래량·거래대금**을 왜곡 없이 100% 정밀 산출
2. **사이드바 '시장/필터 설정' 패널**:
   - 데이터 기준 안내 배너 (15:30 스냅샷 차감 분석 체계)
   - 시장 선택 (`전체`, `코스피`, `코스닥`)
   - 대상 범위 (`시총 상위 200개 (쾌속 모드)`, `시총 상위 500개 (권장 모드)`, `코스피 200/코스닥 150`, `전체 종목`)
   - 최소 시가총액 (억 원) 슬라이더
   - 스마트 수급 필터 (최소 시간외 거래량 비율 %, 최소 시간외 거래대금, 실거래 활성주 선별)
3. **엑셀 형식 데이터 표시 및 완벽한 헤더 토글 정렬**:
   - **1행 헤더 12개 컬럼**: 종목명, 종목코드, 시장, 시가총액, 정규장 종가, 시간외 현재가, 시간외 등락률(%), 정규장 거래량, 시간외 거래량, 시간외 거래대금, 시간외 거래량 비율(%), 시간외 NXT 비중(%)
   - **시간외 거래량 비율(%) 산출 공식**: `{시간외 거래량 / 정규장 거래량} * 100`
   - **시간외 NXT 비중(%) 산출 공식**: `{시간외 NXT 거래량 / 시간외 거래량} * 100`
   - 웹 화면의 인터랙티브 테이블에서 열 헤더 클릭 시 즉시 오름차순/내림차순 토글 정렬
4. **AutoFilter가 완비된 엑셀(.xlsx) 파일 다운로드**:
   - `📥 엑셀 파일 다운로드` 버튼 클릭 시 `openpyxl`의 AutoFilter가 주입되어, 다운로드한 엑셀 파일 내에서도 각 컬럼별 역삼각형(▼) 토글 필터/정렬이 기본 활성화됨.
5. **전문가용 시각적 분석 도구**:
   - 상단 실시간 세션 바 (현재 KST 시간, 정규장/NXT/KRX 애프터마켓 운영 상태 판정, 15:30 스냅샷 연동 상태 표시)
   - 상단 핵심 KPI 요약 카드 4종 (스크리닝 종목수, 시간외 최대 급등주, 시간외 거래량 비율 1위, 시간외 거래대금 1위)
   - Plotly 기반 수급-가격 모멘텀 4분면 스캐터 플롯 (1사분면: 대량 수급 동반 시간외 급등주 포착)

## 🛠️ 실행 방법

### 방법 1. 배치 파일 실행 (가장 간편)
프로젝트 폴더 내 `run_app.bat`을 더블 클릭합니다.

### 방법 2. 명령 프롬프트(CLI) 실행
```bash
python -m streamlit run app.py
```
브라우저에서 `http://localhost:8501`로 자동 연결됩니다.
